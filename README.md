# MyMoneyBot

Telegram-бот + веб-дашборд для управления личными финансами и инвестциями: мультивалютные счета, семейный бюджет, сделки с криптой и аналитика на базе ИИ. Вход на дашборд — только через Telegram, без паролей.

Дополнительно считает **RUI** (Relative Undervaluation Index) — индекс относительной недооцененности для корзины криптовалют и фиатных валют: показывает, кто в корзине отстал от среднего, а кто перегрет.

## Возможности

### 💰 Личные финансы
- Счета в USD, RUB, THB и крипте (TRX, BNB, TON, BTC, ETH, LTC) — баланс каждого счёта в его валюте
- Траты и поступления: ввод одной строкой в боте (`150 кофе`, `+50000 зарплата`, `1,5к продукты`), поддержка суффиксов «к/тыс»
- Переводы между счетами с конвертацией через USD и **фактической суммой зачисления** (реальный курс/комиссии)
- Накопительные счета — отдельным блоком с вердиктом «копишь 🐷 / лезешь в накопления 📉»
- Динамика богатства по дням (график + средняя 7 дней), график трат за период с непрерывной осью
- Все операции правятся и удаляются — балансы откатываются точно (суммы фиксируются на момент ввода)
- Веб-редактор: модальные окна для счетов, операций и переводов, пагинация операций по дням

### 👨‍👩‍👧 Семья
- Общий доступ к счетам и тратам: члены семьи видят и правят всё
- Приглашение по @username (бот доставит лично) или одноразовой ссылкой на 24 часа
- Автор каждой операции виден в интерфейсе; семейные дельты считаются по последнему общему дню

### 💼 Сделки
- Покупка крипты со счёта: монеты живут внутри позиции, P&L считается по живому курсу
- Закрытие по рынку или с фактической суммой; строки сделок не портят график трат
- Одноразовые уведомления при движении цены на ±N% от входа (сбрасываются при смене порога)

### 📊 RUI — индекс недооцененности
Для каждой монеты корзины считается доходность `R = цена_сейчас / цена_N_дн_назад − 1` за окно (24ч / 7д / 30д / 365д). Затем:

```
RUI(монеты) = средний R корзины − R(монеты)
```

- **RUI > 0** — монета отстала от корзины (кандидат на mean reversion)
- **RUI < 0** — монета перегрета относительно корзины

То же самое для фиатных валют (USD / RUB / THB / KRW) — видно, какая валюта слабеет или крепнет относительно группы. История хранится в БД, графики строит ECharts (метрики RUI / R / цена на log-шкале, диапазоны от 1 дня до 5 лет).

### 🤖 ИИ-аналитика (GLM)
- Анализ корзины коинов или фиата «одним кликом» через [z.ai](https://z.ai) (Anthropic-совместимый Messages API), модель с веб-поиском
- Поле «доп. указание» — можно направить анализ (например, «сосредоточься на рисках»)
- Отчёты кэшируются 12 часов и попадают в архив; учёт токенов по пользователям
- Без ключа блок ИИ просто отключается — остальное работает

### 🔁 Калькулятор обмена
- Фиат ↔ крипта по рыночному курсу с возможностью ручной правки (подсказка «±N% к рынку»)
- Промежуточная валюта для реальных схем обмена (например, RUB→THB через USD двумя сделками) с итоговым кросс-курсом
- Замки на суммы — зафиксировать «отдаю» или «получаю» при живом курсе

### 🛡 Прочее
- Вход на дашборд: одноразовый токен из бота (живёт 5 минут) → cookie-сессия; паролей нет вообще
- Ежедневный автопостинг RUI в каналы/чаты по расписанию (часовой пояс настраивается)
- Админ-раздел: список пользователей, их активность, блокировка, статистика ИИ-токенов
- Снапшоты цен и богатства пишутся в БД ежечасно — сервис автономен при отказе внешних API

## Источники курсов

Все источники keyless — API-ключи для курсов не нужны:

| Данные | Источник |
|---|---|
| Крипто-тикеры и дневки | Binance (`/ticker/price`, `/api/v3/klines`) |
| TON (тикер и история) | Kraken (TONUSD, OHLC) — на Binance торги остановлены |
| Фиат-курсы (live) | open.er-api.com |
| История RUB | ЦБ РФ (XML_dynamic) |
| История THB, KRW | frankfurter.dev (данные ЕЦБ) |

Выходные и пропуски закрываются forward-fill — серии непрерывны.

## Технологии

- **Node.js ≥ 18** (ESM), без TypeScript и сборщиков
- [grammY](https://grammy.dev) — Telegram Bot API
- [Express 5](https://expressjs.com) — веб-дашборд и REST API
- [Prisma](https://www.prisma.io) + PostgreSQL 16
- [ECharts](https://echarts.apache.org) — вендорен локально, без CDN
- Docker multi-stage (образ без dev-зависимостей и prisma CLI, non-root пользователь, healthcheck)

## Быстрый старт

Требуется: Node.js ≥ 18, Docker и docker compose (или свой PostgreSQL 16).

```bash
# 1. Клонировать
git clone <repo-url> mymoneybot && cd mymoneybot

# 2. Переменные окружения
cp .env.example .env
# — вписать BOT_TOKEN (у @BotFather) и DB_PASSWORD, остальное можно оставить как есть

# 3. Поднять стек (БД + миграции + приложение)
docker compose up -d --build

# 4. Открыть бота в Telegram и отправить /start
```

Дашборд: `http://127.0.0.1:3005` → «Войти в дашборд» → кнопка в Telegram (`/startweb`) → бот пришлёт одноразовую ссылку.

### Локальная разработка без Docker

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d db   # только БД (порт 5434)
npm install
npx prisma db push
node src/backfill-prices.js   # наполнить историю цен (Binance keyless)
npm start
```

## Веб-дашборд

Вкладки: **Финансы** (счета, операции, сделки, семья) · **COIN** (RUI корзины, история, калькулятор, ИИ) · **FIAT** (RUI валют, история, калькулятор, ИИ) · **Профиль** (пользователь, семья) · **Админ** (для админов).

Основной API (все — после авторизации по cookie-сессии):

```
GET  /api/health                    статус сервиса (публичный)
GET  /api/me                        текущий пользователь
GET  /api/summary                   таблица «Сейчас» по окнам
GET  /api/history, /api/prices      ряды RUI/R/цен (coin|fiat)
GET  /api/rates                     курсы для калькулятора
GET  /api/finance                   счета, сводка, операции (пагинация)
POST /api/finance/accounts          создать счёт
PATCH/DELETE /api/finance/accounts/:id
POST /api/finance/transactions      операция
POST /api/finance/transfer          перевод между счетами
POST /api/finance/deals             сделка; :id/close, PATCH/DELETE
GET  /api/finance/spending          траты по дням
POST /api/family/invite             приглашение в семью
POST /api/ai/analyze                ИИ-анализ (кэшируется)
GET  /api/ai/reports[/:id]          архив отчётов
GET  /api/admin/users, POST :id/block|unblock
```

## Деплой на сервер

Схема: VPS с Docker + Nginx перед приложением (проксирование домена на `127.0.0.1:APP_PORT`), HTTPS через Let's Encrypt.

```bash
# в .env добавить:
#   DEPLOY_SERVER=user@your-server
#   DEPLOY_DIR=/home/user/mymoneybot

./deploy.sh           # rsync + build + up (первый раз и после изменений зависимостей)
./deploy.sh --quick   # без пересборки образа
./deploy.sh --check   # статус контейнеров и health-check

# настроить nginx (HestiaCP или обычный Nginx):
./install-nginx-templates.sh          # с машины разработки, через root SSH
sudo ./install-nginx-templates.sh --local   # прямо на сервере
```

`.env` копируется на сервер отдельно по SCP, в образ не попадает. База данных не публикует порт наружу — доступ только внутри compose-сети.

## Безопасность

- Все секреты — в `.env`, который не попадает в git и в docker-образ
- Паролей нет: вход только через Telegram-бота, одноразовые токены (5 мин, sha256-хеш в БД), httpOnly cookie-сессии
- Админ-права выдаются по списку `ADMIN_USERNAMES` и восстанавливаются из БД
- Блокировка пользователя = мгновенный выход всех его сессий
